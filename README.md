## 快速开始

1. **克隆或下载本仓库**  
   ```bash
   git clone https://github.com/yourname/input.git
```

2. 放置笔记
      在 notes/ 下按数字建立文件夹（如 001/），放入 index.md。
      每个文件夹代表一个章节，按数字顺序拼接。
3. 放置图片
      图片放在对应章节的 images/ 目录中（如 images/001/photo.png）。
      更新 data/images-list.json 以启用转换器的图片浏览功能。
4. 本地预览
      启动一个静态服务器（需 http 协议，防止跨域）：
   ```bash
   npx http-server . -p 8080
   # 或
   python -m http.server 8080
   ```
   访问 http://localhost:8080
5. 部署到 GitHub Pages
      推送至 main 分支，在仓库设置中开启 Pages（源文件夹选 /）。
      建议添加 .nojekyll 文件以禁止 Jekyll 构建。

功能详解

一书到底阅读

系统自动按编号顺序加载 notes/001/、002/… 下所有 Markdown，拼接为一本完整的“书”，上下滚动即可连续阅读，无需手动跳转章节。

智能目录

根据 Markdown 的 #、##、### 标题自动生成层级目录树。
支持目录折叠、全部展开/折叠，以及标题下拉快速跳转。

图片系统

Markdown 中只需使用相对文件名，系统自动寻找对应章节图片。
支持位置修饰符：{left}、{right}、{around} 以及宽度控制。
示例：

```markdown
![实验图](photo.png){right width=300}
```

图注语法：

```markdown
:::image right photo.png 图1：实验流程 :::
```

转换器

通过 converter.html 可在富文本中直接加粗、倾斜、插入标题、表格、图片，并实时生成 Markdown 源码。
图片可从仓库图片列表中浏览选择，一键插入并设置位置与图注。

搜索

基于客户端文本分析的全文搜索，输入关键词即可定位到对应段落标题。

阅读进度

使用 localStorage 记录滚动位置，下次打开自动恢复。
